# 花庭迷宫 · BLOOM MAZE

低多边形第一人称庭园迷宫。桌面键鼠、手机触屏双端，纯静态，无需构建即可玩。

**在线游玩：** https://yjj0339.github.io/bloom-maze/

## 玩法

| | 桌面 | 手机 |
| --- | --- | --- |
| 走动 | `W` `A` `S` `D` / 方向键 | 左半屏摇杆 |
| 转视角 | 鼠标（点击画面锁定指针） | 右半屏拖动 |
| 小跑 | `Shift` | 右下冲刺键 |
| 暂停 | `Esc` / `P` | 右上暂停键 |
| 小地图开关 | `M` | 地图键 |
| 小地图放大 | `Tab` 或点地图 | 点地图 |

穿过走廊收集 **星果**，走到 **花拱门** 即通关。小地图会逐步点亮你走过的路。
评级 S/A/B/C 由用时与星果收集数决定，最佳成绩存在浏览器本地。

## 技术

- Three.js + 自研低多边形建模库（收分石块、连续树篱脊、券石拱门、灯柱、花/蘑菇/顶植树），全部真几何，flat shading
- 迷宫：种子化 DFS 递归回溯 + braid 成环；墙段 AABB + 空间哈希做圆形碰撞，分轴推挤实现自然贴墙滑行
- 探索式小地图：逐格 reveal 淡入，跟随窗 / 全图两档，可切北向上或随视角旋转
- 音效全 WebAudio 合成（脚步、拾取、穿门、胜利、环境垫音、随机鸟鸣），零外部资源
- GPU 粒子（花瓣/花粉在顶点着色器内漂移自旋）、渐变天穹 + 太阳辉光 shader、跟随玩家的软阴影、桌面档 UnrealBloom
- 竖屏 FOV 纵横比补偿；触屏自动降画质档

## 本地开发

```bash
npm install          # 装 three + esbuild
npm run build        # 打包 src/ -> bundle.js
npm start            # 本地静态服务 http://127.0.0.1:8155/
```

`src/` 为源码，仓库根目录的 `index.html` / `style.css` / `bundle.js` 是可直接托管的产物。
